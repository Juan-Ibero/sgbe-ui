# Historias de Usuario — SGBE-UI

## HU-001: Registro de usuario
**Como** estudiante universitario,
**Quiero** registrarme con mi correo institucional,
**Para** acceder de forma segura a la plataforma.
**Criterio:** El sistema valida el correo y envía un correo de verificación.

## HU-002: Inicio de sesión
**Como** estudiante registrado,
**Quiero** iniciar sesión con mis credenciales,
**Para** acceder a mi panel personalizado de bienestar.
**Criterio:** El sistema genera un token JWT válido por 24h.

## HU-003: Registro emocional diario
**Como** estudiante,
**Quiero** registrar mi estado emocional cada día,
**Para** hacer seguimiento de mis tendencias de bienestar.
**Criterio:** Se puede registrar una emoción por día con nivel de estrés del 1 al 10.

## HU-004: Visualización del dashboard
**Como** estudiante,
**Quiero** ver un panel con mis tendencias emocionales,
**Para** entender mejor mis patrones de bienestar.
**Criterio:** El dashboard muestra una gráfica de los últimos 7 días.

## HU-005: Gestión de hábitos saludables
**Como** estudiante,
**Quiero** crear y hacer seguimiento de hábitos saludables,
**Para** mejorar mi rutina diaria y mantener una racha de cumplimiento.
**Criterio:** Se pueden crear hábitos, marcarlos como cumplidos y ver la racha actual.
